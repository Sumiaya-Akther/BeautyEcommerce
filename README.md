### 🔄 Checkout Flow (3 Connected Pages)
The checkout process is divided into **three separate HTML pages**, connected through internal links:

1. ✅ `checkout.html` – Enter delivery and billing information
2. 💳 `paymentCheckout.html` – Select payment method
3. 📦 `confirmCheckout.html` – Final order confirmation

Each step is linked from the previous page, creating a seamless multi-step checkout experience.
